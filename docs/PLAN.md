# План разработки сайта-портфолио

Многостраничный сайт проектов на GitHub Pages: https://e1hanson.github.io/

Требования: переключатель темы (как на устройстве / светлая / тёмная), типографика без засечек и курсивов, компоновка по золотому сечению, неоморфизм, hover-эффекты, адаптивы под все медиазапросы.

---

## 1. Ключевые решения

| Вопрос | Решение | Почему |
|---|---|---|
| Генератор | **Astro** (актуальная 7.x) | Многостраничность из коробки, общие layout-ы и компоненты без копипасты, на выходе чистый HTML/CSS с нулём лишнего JS |
| Контент проектов | **Content Collections**: один проект = одна папка `src/content/projects/<slug>/` с `index.md` и изображениями | Добавить проект = положить папку с описанием и обложкой, страница и карточка создаются сами |
| Публикация проектов | **По стадиям разработки**, регламент — [PUBLISHING.md](PUBLISHING.md) | Проект появляется в каталоге с первой стадии и обновляется по мере продвижения |
| Стили | **Чистый CSS** на custom properties, `@layer`, `clamp()`, container queries | Неоморфизм и φ-сетка требуют собственной системы токенов; Tailwind/UI-киты здесь мешают |
| Скрипты | Ванильный JS/TS: тема, фильтр проектов, появление при скролле | Минимальный вес, всё остальное делает CSS |
| Шрифты | Self-hosted variable `woff2` (кириллица + латиница) | Скорость, нет запросов к сторонним серверам |
| Хостинг | GitHub Pages через GitHub Actions | Автодеплой при каждом push в `main` |
| Язык сайта | **Русский** (`lang="ru"`) | Решено 2026-09-21 |
| Подпись автора | **Иван** | Решено 2026-09-21; расширенное био — позже |
| Контакты | **Пока не публикуем**: без страницы контактов, без ссылок на соцсети и почту | Решено 2026-09-21 |
| Акцентные цвета | **Голубой, графитовый, фуксия** (значения — раздел 3.2) | Решено 2026-09-21 |

## 3. Дизайн-система

### 3.1. Золотое сечение (φ = 1,618)

- **Отступы и размеры** — ряд Фибоначчи (соседние числа дают φ): `3 · 5 · 8 · 13 · 21 · 34 · 55 · 89 · 144 · 233` px (в коде — в `rem`).
- **Кегли** — шаг `√φ ≈ 1,272` (два шага = φ; чистый φ даёт слишком резкие скачки): `12,6 · 16 · 20,4 · 25,9 · 32,9 · 41,9 · 53,3 · 67,8` px, плавное масштабирование через `clamp()`.
- **Интерлиньяж**: основной текст — `1,618`, заголовки — `1,272`, крупные дисплейные — `1,1`.
- **Двухколоночные секции**: `grid-template-columns: 1.618fr 1fr` (61,8 % / 38,2 %), с чередованием стороны.
- **Контейнеры**: `1597` (максимум) → `987` (контент) → `610` (текстовая колонка, ~68 знаков в строке) — каждый в φ раз меньше предыдущего.
- **Пропорции**: обложки и карточки — золотой прямоугольник `1,618 : 1`; hero — `61,8svh`; фокусные точки композиции — на линиях 38,2 % / 61,8 %.
- **Вертикальный ритм секций**: `89` px (мобильные) → `144` px (десктоп).
- **Радиусы**: `8 · 13 · 21 · 34` px.
- **Тени**: пары «смещение / размытие» `5/13 · 8/21 · 13/34` (размытие = смещение × φ²).
- **Длительности анимаций**: `89 · 144 · 233 · 377` мс.

### 3.2. Неоморфизм

- **Принцип**: элементы того же цвета, что и фон; объём создаётся парой теней — светлой (сверху-слева) и тёмной (снизу-справа).
- **Базовые токены темы** (меняются только они, всё остальное выводится из них): `--surface`, `--shadow-light`, `--shadow-dark`, `--text`, `--text-muted`, `--accent`.
  - Светлая: холодный светло-серый фон (~`#E7EBF0`), белая и серо-голубая тени.
  - Тёмная: графитовый фон (~`#23262B`), отдельно подобранные тени + тонкий внутренний блик, чтобы объём не «грязнил».
  - Акцентная тройка: **голубой** (основной акцент — ссылки, фокус, активные состояния), **фуксия** (вторичный — выделение, свечение при hover, текущая стадия проекта), **графит** (основа тёмной темы и цвет текста в светлой). Фирменный градиент голубой → фуксия — для шкалы стадий, подчёркивания ссылок и тумблера темы.

| Роль | Светлая тема (`#E7EBF0`) | Тёмная тема (`#23262B`) |
|---|---|---|
| Текст (графит / светлый) | `#262A30` — 12,0 : 1 | `#E6EAF0` — 12,6 : 1 |
| Приглушённый текст | `#566070` — 5,3 : 1 | `#A4ADBA` — 6,7 : 1 |
| Голубой — текст и ссылки | `#0A66B3` — 4,9 : 1 | `#5CBBFF` — 7,2 : 1 |
| Голубой — заливка, свечение | `#2EA6FF` (на ней графитовый текст `#16181C` — 6,8 : 1) | `#5CBBFF` |
| Фуксия — текст | `#B80F75` — 5,2 : 1 | `#FF5FBA` — 5,5 : 1 |
| Фуксия — заливка, свечение | `#F0249B` (3,2 : 1 — только крупные элементы) / `#D4148A` под белый текст — 4,9 : 1 | `#FF5FBA` (на ней графит `#16181C` — 6,4 : 1) |

Значения предварительные, посчитаны по формуле контраста WCAG; финальная подгонка — на этапе 3 по стайлгайду.
- **Уровни объёма**: `flat` · `raised` · `raised-lg` · `pressed` (вдавленный, inset) · `concave` / `convex` (градиент).
- **Компоненты**: шапка и навигация (текущий пункт — вдавленная «пилюля»), переключатель темы, кнопки (основная / вторичная / иконка), карточка проекта, тег, сегментированный фильтр, поля ввода, таймлайн, шкала навыка, хлебные крошки, навигация «пред. / след.», подвал, мобильное меню.
- **Страховка доступности** (слабое место неоморфизма — контраст):
  - контраст текста ≥ 4,5 : 1, границ интерактивных элементов ≥ 3 : 1;
  - интерактивность обозначается не только тенью — ещё акцентом, иконкой, подписью;
  - заметное кольцо `:focus-visible`;
  - в `prefers-contrast: more` и `forced-colors: active` появляются явные границы.

### 3.3. Типографика

- Только гротески. Кандидаты с кириллицей: для текста — Onest / Manrope / Golos Text, для заголовков — Unbounded / Geologica. Финальный выбор — на этапе 3 по живому образцу в обеих темах.
- **Без курсивов**: `font-style: normal` для `em, i, cite, dfn, address, var, blockquote`; акцент передаётся насыщенностью и цветом; `font-synthesis: none` (браузер не рисует псевдокурсив); курсивные начертания не подключаются.
- Вариативные шрифты, `font-display: swap`, preload основного начертания, сабсеты кириллица + латиница, табличные цифры для дат и чисел.

### 3.4. Переключатель темы

- По умолчанию — **как на устройстве** (`prefers-color-scheme`), сайт реагирует на смену системной темы на лету.
- Ручной выбор: неоморфный тумблер «солнце / луна» в шапке; выбор сохраняется в `localStorage`; в подвале — сброс «Как на устройстве».
- Техника: атрибут `data-theme` на `<html>`; инлайн-скрипт в `<head>` до отрисовки (без вспышки чужой темы); свойство `color-scheme`; `<meta name="theme-color">` для обеих тем; синхронизация между вкладками; плавный переход цветов и теней; круговое раскрытие через View Transitions API как прогрессивное улучшение.

### 3.5. Hover-эффекты и движение

- Hover — только внутри `@media (hover: hover) and (pointer: fine)`; на тач-экранах вместо него состояние нажатия `:active`.
- Набор эффектов:
  - карточка проекта — приподнимается (тень на уровень выше + сдвиг вверх), обложка мягко увеличивается внутри маски, стрелка сдвигается;
  - кнопка — `raised` → выше при hover → `pressed` при нажатии;
  - пункты навигации и теги — вдавливание;
  - иконки — акцентное свечение;
  - текстовые ссылки — прорисовка подчёркивания;
  - фирменный эффект (опционально): источник света следует за курсором — тени карточек меняют угол.
- Появление блоков при скролле (IntersectionObserver / scroll-driven animations).
- Переходы между страницами: `@view-transition { navigation: auto; }`.
- `prefers-reduced-motion: reduce` — без трансформаций и переходов, только мгновенная смена состояния.
- Производительность: `box-shadow` не анимируется массово — переход делается через прозрачность псевдоэлемента с готовой тенью.

### 3.6. Адаптивность

- Mobile-first и «резиновая» основа: `clamp()` для кеглей и отступов, сетки `auto-fit / minmax`, container queries для карточек, единицы `svh / dvh`, `env(safe-area-inset-*)` для вырезов экрана.
- **Брейкпоинты по ширине**: `360 · 480 · 768 · 1024 · 1280 · 1440 · 1920 · 2560`.

| Ширина | Поведение |
|---|---|
| < 480 | 1 колонка, мобильное меню, hero стопкой, секции 89 px |
| 480–767 | 1 колонка шире, карточки крупнее |
| 768–1023 | сетка 2 колонки, разделение 61,8 / 38,2 в ключевых секциях |
| 1024–1279 | полная навигация в шапке, все φ-разделения, секции 144 px |
| 1280–1919 | сетка 3 колонки |
| 1920–2559 | контейнер упирается в 1597, шкала кеглей на ступень выше |
| ≥ 2560 | увеличение корневого кегля, чтобы сайт не «терялся» на 4K |

- **Прочие медиазапросы**: `orientation: landscape` + малая высота (компактные шапка и hero), `hover / pointer`, `prefers-color-scheme`, `prefers-reduced-motion`, `prefers-contrast`, `forced-colors`, `print` (чистая версия без теней), плотность пикселей (`srcset`, AVIF / WebP).
- Изображения: компонент `<Picture>` — AVIF/WebP, `srcset`, lazy-loading, заданные размеры (без сдвигов макета).

### 3.7. Стадии проектов и пустые состояния

- **Две дорожки стадий** (подробно — [PUBLISHING.md](PUBLISHING.md)): цифровые проекты (идея → прототип → разработка → бета → релиз → поддержка) и здания / интерьеры (концепция → эскизный проект → рабочая документация → реализация → завершён).
- **Шкала стадий** на странице проекта — неоморфный степпер: пройденные стадии — выпуклые, текущая — вдавленная с акцентом фуксии, будущие — плоские; линия прогресса — градиент голубой → фуксия. На узких экранах — вертикальная.
- **Хронология** — записи по стадиям: дата, что сделано, изображения.
- **Метка стадии** на карточке каталога; фильтр каталога по дорожке и стадии.
- **Блок «Сейчас в работе»** на главной — проекты, не дошедшие до финальной стадии.
- **Пустые состояния**: каталог и главная без проектов выглядят завершённо — неоморфная иллюстрация-заглушка и короткий текст, без «битых» сеток.

## 6. Риски

| Риск | Как снимаем |
|---|---|
| Неоморфизм даёт низкий контраст и неочевидные кнопки | Правила из раздела 3.2: контраст, акцент, фокус, режимы высокого контраста |
| Тёмная тема в неоморфизме выглядит «грязно» | Отдельная настройка теней и внутренний блик, проверка на разных экранах |
| Много размытых теней тормозят на мобильных | Ограничение числа уровней, анимация через псевдоэлементы, проверка на телефоне |
| Чистая φ-шкала кеглей слишком резкая | Шаг √φ |
