# e1hanson.github.io

Многостраничный сайт-портфолио проектов.

**Адрес:** https://e1hanson.github.io/ · **Статус:** в разработке

## О проекте

- Переключатель темы: по умолчанию как на устройстве, вручную — светлая или тёмная
- Типографика: только гротески (без засечек), без курсивов
- Компоновка элементов и секций по правилам золотого сечения (φ = 1,618)
- Стилистика — неоморфизм (soft UI); акцентные цвета — голубой, графитовый, фуксия
- Проекты публикуются по стадиям разработки: от идеи до релиза, с хронологией на странице проекта
- Hover-эффекты для устройств с курсором, отдельные состояния нажатия для тач-экранов
- Адаптивная вёрстка под все медиазапросы: от 320 px до 2560+ px, ориентация, `prefers-*`, печать

## Стек

- [Astro](https://astro.build/) — статическая генерация страниц, проекты хранятся как Markdown-файлы
- Чистый CSS: custom properties, `@layer`, `clamp()`, container queries
- Ванильный JS — только для темы, фильтра проектов и анимаций появления
- Деплой: GitHub Actions → GitHub Pages

## Запуск локально

Нужен Node.js 22.12 или новее.

```bash
npm install
npm run dev      # http://localhost:4321 — черновики проектов видны
npm run build    # продакшн-сборка в dist/ — черновики исключены
```

Проекты лежат в `src/content/projects/<slug>/index.md`; формат записи и стадии — в регламенте публикации.
